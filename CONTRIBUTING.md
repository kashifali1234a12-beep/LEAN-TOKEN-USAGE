# Contributing

Ideas welcome — with evidence.

1. Run `usage_report.py` on a real session **before** your change.
2. Apply the change (a new rule, a better handoff, a script improvement).
3. Run it again **after** on comparable work.
4. Open a PR with both tables and a short note on why quality and pace stayed the same.

Rules that save tokens by lowering the model, the effort, or the amount of real work are out of scope.
